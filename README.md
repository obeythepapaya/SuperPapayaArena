# Super Papaya Arena

A 3v3 arena combat game in the browser. Play online with friends: one player clicks **Host a game** and shares the 4-letter code, the others click **Join**.

Controls: WASD move, mouse look, left click attack (hold for heavy), right click block / aim, Shift dodge, Space jump, Q R F abilities, 1 / 2 swap weapon, E potion, Tab scoreboard, Esc menu.
